# Revature-RBAC

    - Would recommend running this in VMware / other virtual machine 
    - Make sure to create a python venv, then run `pip install -r requirements.txt`.
    - Before starting the app, first run populate.py to create and populate the database
    - "Flask run" to start, will run on local machine
    - Test out some requests, I added a test endpoint that should return 200 to verify app is running
